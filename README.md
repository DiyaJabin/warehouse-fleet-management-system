## 📖 Overview

The **ROS2 Warehouse Fleet Management System (AWFMS)** is a simulation-based robotics project that aims to coordinate multiple autonomous mobile robots operating inside a warehouse environment.

The project focuses on centralized fleet management, intelligent task allocation, real-time robot monitoring, and dynamic lane reservation to prevent traffic conflicts during multi-robot operation.

The system is being developed using **ROS 2 Jazzy**, **Gazebo Harmonic**, and **Python**, with a **Streamlit dashboard** for visualization and fleet management.

---

## 🎯 Objectives

- Simulate a multi-robot warehouse environment
- Manage autonomous delivery tasks
- Coordinate warehouse traffic
- Prevent robot collisions using Dynamic Lane Reservation
- Monitor robot status in real time
- Visualize fleet operations through a Streamlit dashboard
